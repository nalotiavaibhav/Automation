HubSpot is the default CRM for most Flowmax customers and the most polished integration. Setup is a 3-step OAuth flow and takes about 3 minutes.

## What it does

- **Contact upsert** — on every call, the caller's phone is upserted into HubSpot Contacts.
- **Deal creation** — if the call captures a service request, a Deal is created on your default pipeline.
- **Call log** — full Vapi transcript + recording URL is attached as a HubSpot Call activity on the contact.
- **Meeting** — if the AI books an appointment, it appears as a HubSpot Meeting.

## OAuth setup

1. In HubSpot, go to **Settings → Account Setup → Integrations → Private Apps** (or use a public app — Flowmax supports both flows).
2. Create a private app called "Flowmax AI Receptionist".
3. Under **Scopes**, enable:
   - `crm.objects.contacts.read` · `crm.objects.contacts.write`
   - `crm.objects.deals.read` · `crm.objects.deals.write`
   - `crm.objects.calls.read` · `crm.objects.calls.write`
   - `crm.objects.meetings.read` · `crm.objects.meetings.write`
4. Copy the Private App Token.
5. In `.env.local`:
   ```
   HUBSPOT_CLIENT_ID=...
   HUBSPOT_CLIENT_SECRET=...
   HUBSPOT_APP_ID=...
   HUBSPOT_PRIVATE_APP_TOKEN=<the token from step 4>
   DEFAULT_CRM_PROVIDER=hubspot
   ```
6. Restart `npm run dev` and place a test call. The contact + deal + call should appear in HubSpot within 5–10 seconds of call end.

## Deal stage mapping

Flowmax uses a 5-step generic pipeline. HubSpot's default sales pipeline stages map as follows:

| Flowmax stage | HubSpot stage |
|---|---|
| `new` | appointmentscheduled |
| `contacted` | qualifiedtobuy |
| `qualified` | presentationscheduled |
| `booked` | decisionmakerboughtin |
| `completed` | closedwon |

If your HubSpot pipeline uses custom stages, edit the `HUBSPOT_STAGE_MAP` in `lib/crm/adapters/hubspot.ts`. A settings UI for this is on the roadmap.

## Troubleshooting

**"No CRM credentials found"** — `HUBSPOT_PRIVATE_APP_TOKEN` not set or not loaded. Restart `next dev` after editing `.env.local`.

**Contact created twice** — Two different phone formats hit the upsert (e.g. `+15551234567` vs `(555) 123-4567`). Flowmax normalizes to E.164 before upsert; if you see duplicates, file an issue with the two phone strings.

**Deal stuck in "new"** — A deal moves only when you drag the card in the pipeline view OR an upstream API call updates it. Flowmax does not auto-promote deal stages.

**Call activity missing** — Check that `crm.objects.calls.write` is in the granted scopes; HubSpot rejects writes silently if missing.

## FAQ

**Will Flowmax delete data in HubSpot?** No. The adapter is write-and-update only.

**Can I disconnect?** Yes — clear `HUBSPOT_PRIVATE_APP_TOKEN` in `.env.local` and restart. HubSpot keeps the data it has.

**Does it support multiple HubSpot accounts?** Not in v1. Multi-tenant CRM is part of the multi-tenancy project.
