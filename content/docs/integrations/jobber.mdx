> **Beta.** The Jobber adapter handles client upsert and request creation. Quote/invoice wiring is partial.

## What it does

- **Client upsert** to Jobber Clients
- **Request creation** for each captured service inquiry
- **Note** attached with the call transcript

## Setup

Jobber uses OAuth 2.0.

1. Register a developer app at https://developer.getjobber.com
2. Set redirect URI to `https://<your-app-url>/api/integrations/jobber/callback`
3. Required scopes: `read_clients`, `write_clients`, `read_requests`, `write_requests`, `read_quotes`, `write_quotes`
4. Wire the resulting client/secret into `.env.local` and connect via Settings → Integrations

## Limits

- The Jobber GraphQL API has tight rate limits on the lower tiers — heavy bursts of calls may be queued
- Quote line items are not auto-populated; quotes are created as empty drafts

## FAQ

**Better suited for which businesses?** Field services with strong scheduling needs — landscaping, cleaning, HVAC. Less polished for emergency-trade workflows.
